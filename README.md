# The Perfect Guess Game

## Description
The Perfect Guess Game is an interactive number guessing game where the player has to guess a randomly chosen number between 1 and 100. The player has a total of 5 tries to guess the correct number. After each guess, the game provides feedback on whether the guessed number is too high or too low. If the player fails to guess the number within the allotted tries, hints about the number's parity (even or odd) are provided for the next attempts.

## How to Play
1. Start the game by running the Python script.
2. You will be prompted to enter your guess.
3. Enter a number between 1 and 100.
4. The game will inform you if your guess is too high or too low.
5. You have a total of 5 tries to guess the correct number.
6. If you guess correctly, you win! If you run out of tries, the game will reveal the correct number and provide hints for future attempts.

## Steps to Clone and Run the Game
1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   ```
   Replace `<repository-url>` with the URL of the repository where the game is hosted.

2. **Navigate to the project directory**:
   ```bash
   cd the-perfect-guess-game
   ```

3. **Run the game**:
   Make sure you have Python installed on your machine. Then run the following command:
   ```bash
   python "the perfect guess.py"
   ```

Enjoy playing The Perfect Guess Game!
